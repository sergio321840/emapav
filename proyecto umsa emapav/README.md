# Proyecto UMSA EMAPAV

Frontend local independiente, organizado con el patron MVC en JavaScript puro.

- `model/`: datos del sitio.
- `view/`: renderizado de la interfaz.
- `controller/`: eventos y comportamiento.
- `index.html`: entrada del frontend.
- `styles.css`: estilos visuales.

No usa Next.js, PHP, APIs, base de datos ni servidor remoto. Se puede abrir directamente con `index.html` o servir localmente desde esta carpeta.
